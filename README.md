# Amortized-SRE


### Requirements

- [QETLAB](https://qetlab.com/)
- [Manopt](https://www.manopt.org/)

### Rz_magic_generation

This folder includes

- The amortized (and strict) log robustness of magic (and stabilizer extent) of single-qubit $$R_z(\theta)$$ gate with varying $$\theta$$. We calculate these by exhausting all single-qubit stabilizer states as inputs.

- Lower bounds on the amortized SRE of single-qubit $$R_z(\theta)$$ gate with varying $$\theta$$. We calculate this by using the Riemannian optimizition of the input state on unit sphere.
